# Translation review status — 2026-10-28

Languages: th, en, zh-Hans, my, km. Dictionaries are authored locally in src/lib/i18n. No user information was submitted to any translation service.

All non-Thai health and privacy wording is a draft translation requiring hospital review. Rendered glyphs and preserved form state are software checks; they do not certify linguistic or clinical accuracy.

Required human review:

- Medical, surgical, medication/supplement and drug/food/other allergy histories; none and unknown choices.
- Immediate-family relationship/disease terms and questionnaire questions, response options and safety/review reasons.
- Healthcare coverage, insurer/hospital, cost estimates and the distinction between staff verification and entitlement to reimbursement.
- Privacy purposes, rights, retention, controller/DPO contacts and notice acknowledgement. The existing notice still requires hospital/DPO approval; software must not invent legal terms or retention periods.
- Price/date acceptance, interest success vs confirmed appointment, preparation and recovery messages.
- Promotional captions/alt text against the original Thai images. Do not derive prices or eligibility from the image artwork.

For custom API questionnaires, submit translations and rule translations as part of a new questionnaire draft, then use the existing approval process. The source labels/answer values remain canonical. Partial translations are accepted and missing values use the Thai/original fallback.

Arbitrary hospital package names, service descriptions and preparation text continue to use approved catalogue content. Add approved dictionary entries or approved catalogue translation metadata in a future catalogue change; do not automatically translate patient free text. The current implementation does not claim complete translation of arbitrary administrator-authored catalogue data.

Local fonts are SIL OFL Noto Sans SC, Myanmar and Khmer (public/fonts, with licence files). Review actual devices and screen-reader pronunciation separately from browser screenshots.
