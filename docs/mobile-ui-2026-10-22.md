# Mobile application interface — 22 October 2026

The existing Next.js application now uses mobile navigation and labelled data cards at widths of 800px and below. Desktop tables and the staff sidebar remain available above that breakpoint.

## Interface changes

- Public bottom navigation: packages, registration, appointment lookup, contact, staff login. Hidden during login and account/MFA enrollment.
- Staff bottom navigation: role-aware home and shortcuts, plus the complete existing menu in a Radix modal drawer. The drawer supports Escape, focus trapping, accessible titles, and focus restoration.
- Shared responsive tables cover dashboard bookings, administrative records/import previews, user management, and the generic sortable table. Each mobile cell displays its column label. Existing buttons and input elements are rendered once; account and saving actions retain their existing handlers.
- Generic tables include a mobile sorting select because their column headings are visually hidden in card mode.
- Compact sticky staff header, single-column mobile forms, touch targets, readable input sizing, and space for bottom navigation and device safe areas. Browser zoom remains enabled.
- Staff management action buttons use a short visible label and retain the account email in their accessible name.

## Verification

- Production build: passed (Next.js 16.4.2, webpack).
- TypeScript: passed.
- ESLint: zero errors; one existing TanStack Table React Compiler compatibility warning.
- Unit/default test suite: 54 passed, 34 skipped.
- Focused Playwright suite: 9 passed (mobile navigation and card layout, homepage, package saving at 390px, invitation/MFA enrollment, temporary-password enrollment).
- Browser viewport checks: 320px public, 390px staff/forms, 1280px desktop; no page horizontal overflow in the tested mobile screens.

Browser checks use synthetic accounts on the localhost development database, not the VPS. Screenshots were inspected for public and staff mobile screens.

## Deployment

These changes are local source changes. No production deployment or database migration is required by this UI change, and none has been performed. Existing authentication, RBAC, MFA enforcement, and package validation remain in place. Physical iOS/Android device testing has not been performed.
