# เลือกและเพิ่มรายละเอียดในแบบลงทะเบียน — 28 ตุลาคม 2569

ต่อยอดตัวเลือกประวัติสุขภาพให้ครอบคลุมช่องรายละเอียดที่เหลือ:

- โรงพยาบาลตามสิทธิ / บริษัทประกัน / รายละเอียดเพิ่มเติม
- ความช่วยเหลือหรือสิ่งอำนวยความสะดวก
- ประวัติการผ่าตัด
- รายละเอียดประวัติครอบครัว และรายละเอียดโรคของญาติแต่ละรายการ
- คำถามประเภทข้อความจาก API ใช้รายการที่กำหนดในคำถามและเพิ่มข้อความเองได้

ทุกช่องรายละเอียดเลือก ไม่มี / ไม่ทราบ / มี แล้วเลือกหลายรายการ เพิ่ม แก้ไข หรือลบข้อความเองได้ ช่อง optional ยังคงเว้นไว้ได้ ชื่อ เบอร์โทร อีเมล เลขเอกสาร วันเกิด และคำถามตัวเลขใช้ชนิดช่องที่เหมาะสม ตัวเลือกคำถาม single/multiple และกฎที่อนุมัติไว้ไม่เปลี่ยน

ใช้ HealthHistoryPicker ร่วมกันและ healthSelections แบบ optional ใน encrypted person payload ของเดิม เพิ่ม surgeryHistory, assistance, treatmentRightDetails, familyNcdDetails โดยยังเก็บข้อความสรุปในฟิลด์เดิม เจ้าหน้าที่อ่านได้ด้วยหน้าเดิม ไม่มี SQL migration ข้อความคำถามและหมายเหตุญาติยังส่งชนิด string เดิมเพื่อความเข้ากันได้ หลังเปิดแบบร่างจะแสดงข้อความเดิมเป็นรายการเพิ่มเติมโดยไม่เดาโรค

useFieldArray ผูกหมายเหตุญาติกับรายการที่คงที่ เมื่อลบแถวก่อนหน้า ข้อมูลของญาติที่เหลือไม่สลับกัน ช่องข้อมูลครอบครัวที่ซ่อนเมื่อเลือกไม่มี/ไม่ทราบไม่ถูกส่งหรือขัดขวาง validation

เพิ่มคำแปลทั้งห้าภาษา; ต้องให้ผู้เชี่ยวชาญตรวจคำแปลสุขภาพก่อนใช้งานจริง ไม่เพิ่มเกณฑ์คลินิกหรือสรุปความเสี่ยง ไม่ส่งข้อมูลไปบริการภายนอก OTP ยังคงปิด
