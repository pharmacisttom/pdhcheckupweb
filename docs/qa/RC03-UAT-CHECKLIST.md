# RC03 Clinical & Administrative UAT Checklist

**Hospital:** Pluak Daeng Hospital (โรงพยาบาลปลวกแดง จังหวัดระยอง)  
**Environment:** ISOLATED TEST / STAGING ENVIRONMENT ONLY  
**Release Candidate:** RC03 (`feature/rc03-clinician-feedback-7`)

## 1. Patient / Registration Journey (ผู้รับบริการ)

- [ ] **1.1 Registration Navigation & Answer Retention (ย้อนกลับไม่สูญหายข้อมูล):**
  - [ ] กรอกข้อมูลส่วนตัวในหน้าแรก แล้วกดย้อนกลับ/ไปข้างหน้า ข้อมูลทุกช่องยังคงอยู่ครบถ้วน
  - [ ] กรอกข้อมูลแบบประเมินสุขภาพครบถ้วน กดย้อนกลับไปหน้าข้อมูลส่วนตัว แล้วกลับมาหน้าประเมิน ข้อมูลคำตอบยังอยู่สมบูรณ์
  - [ ] รีเฟรชหน้าเว็บขณะอยู่ในขั้นตอนการลงทะเบียน ข้อมูลที่บันทึกไว้ได้รับการกู้คืนอัตโนมัติ

- [ ] **1.2 Thai National ID Validation (การตรวจเลขบัตรประชาชน 13 หลัก):**
  - [ ] กรอกตัวเลขไม่ครบ 13 หลัก (เช่น 12 หลัก) ระบบแสดงข้อความแจ้งเตือน "กรุณากรอกเลขบัตรประชาชนให้ครบ 13 หลัก"
  - [ ] กรอกตัวเลข 13 หลักที่ Checksum ผิด ระบบแสดงข้อความแจ้งเตือน "เลขบัตรประชาชนไม่ถูกต้อง"
  - [ ] Paste ตัวเลขเกิน 13 หลัก (เช่น 14-15 หลัก) ตัวเลขไม่ถูกตัดหายทิ้งเงียบๆ และยังคงแสดง Error ให้ผู้ใช้แก้ไข
  - [ ] เลือกประเภทเอกสารเป็น "หนังสือเดินทาง" หรือ "ยังไม่ระบุ" ระบบยอมรับตามนโยบายเดิม

- [ ] **1.3 Measurements & BMI Display (การระบุส่วนสูง น้ำหนัก และค่า BMI):**
  - [ ] ระบุส่วนสูง (ซม.) และน้ำหนัก (กก.) ระบบแสดงผล BMI ทันที ทศนิยม 2 ตำแหน่ง (เช่น 170 ซม. 70 กก. = 24.22 kg/m²)
  - [ ] ข้อความระบุชัดเจนว่า "BMI เป็นค่าคำนวณเพื่อแสดงข้อมูลเท่านั้น ยังไม่ใช้จัดกลุ่มความเสี่ยงหรือเลือกแพ็กเกจ จนกว่าแพทย์จะรับรองเกณฑ์"
  - [ ] ระบุวันเกิด ระบบคำนวณอายุตามเวลาประเทศไทย (Asia/Bangkok) และแสดงกลุ่มอายุ "น้อยกว่า 35 ปี" หรือ "ตั้งแต่ 35 ปีขึ้นไป" ถูกต้อง

- [ ] **1.4 Family NCD History (ประวัติโรค NCD ในครอบครัว):**
  - [ ] เลือก "มี" ญาติสายตรงเป็นโรค NCD ระบบแสดง Checkbox แยกตามความสัมพันธ์: มารดา, บิดา, พี่น้อง, บุตร
  - [ ] สามารถเลือกติ๊กโรคได้หลายโรคต่อหนึ่งความสัมพันธ์ (เช่น บิดาเป็นทั้งเบาหวานและความดันโลหิตสูง)
  - [ ] ไม่บังคับระบุชื่อญาติ เพื่อรักษาความเป็นส่วนตัวตามกฎหมาย PDPA

- [ ] **1.5 Snoring History (ประวัตินอนกรน):**
  - [ ] แสดงตัวเลือก "มี", "ไม่มี", "ไม่ทราบ" ในแบบประเมิน
  - [ ] ระบบไม่วินิจฉัยโรคหยุดหายใจขณะหลับ (Sleep Apnea) โดยอัตโนมัติ

- [ ] **1.6 Group / Organization Registration (การลงทะเบียนแบบกลุ่ม/หน่วยงาน):**
  - [ ] สลับรูปแบบลงทะเบียนเป็น "หน่วยงาน / กลุ่ม"
  - [ ] เลือกหน่วยงานจากรายชื่อหน่วยงานที่เปิดใช้งาน
  - [ ] ระบุชื่อผู้ประสานงานหลักและเบอร์โทรศัพท์
  - [ ] ยืนยันว่าสมาชิกกลุ่มคนอื่นไม่สามารถมองเห็นข้อมูลสุขภาพส่วนบุคคลของผู้รับบริการคนนี้

## 2. Staff & Administrative Workflows (เจ้าหน้าที่และผู้ดูแลระบบ)

- [ ] **2.1 Contact Requests Management (`/admin/contact-requests`):**
  - [ ] ตารางแสดงผลแบบ Responsive บนหน้าจอ Desktop (1440px) และ Mobile (390px, 320px)
  - [ ] ค้นหาตามเลขอ้างอิง (Reference Search) ทำงานถูกต้อง
  - [ ] ตัวกรองสถานะ (Status Filter) กรองรายการได้ถูกต้อง
  - [ ] Server-side Pagination แบ่งหน้าละ 20 รายการถูกต้อง
  - [ ] ข้อมูลในตารางไม่เปิดเผยชื่อคนไข้หรือคำตอบสุขภาพก่อนเปิดดูรายละเอียด

- [ ] **2.2 Contact Request Detail Dialog (หน้าต่างรายละเอียดคำขอ):**
  - [ ] กดปุ่ม "รายละเอียด" เปิด Radix Modal แสดงข้อมูลการติดต่อและคำตอบสุขภาพ
  - [ ] กดปุ่ม Escape หรือปุ่มปิด หน้าต่างปิดลง และ Focus กลับมาที่ปุ่มเดิมบนตาราง
  - [ ] การเปลี่ยนสถานะ (Status Transition), การทำใบเสนอราคา (Quotation), และการนัดหมาย (Scheduling) ทำงานสมบูรณ์
  - [ ] มีการบันทึก Audit Log ทุกครั้งที่มีการเปิดดูข้อมูลคำขอ

- [ ] **2.3 Questionnaire Draft Workspace (`/admin/questionnaires`):**
  - [ ] ตรวจสอบรายการแบบประเมินฉบับปัจจุบัน
  - [ ] ปุ่ม "สร้างฉบับร่าง RC03 เพื่อแพทย์ทบทวน" สร้างฉบับร่างใหม่ที่มีข้อคำถามนอนกรนโดยไม่แก้ไขฉบับที่เผยแพร่อยู่เดิม
  - [ ] ต้องได้รับการลงนามอนุมัติจากแพทย์ผู้รับผิดชอบก่อนกด "เผยแพร่" ใช้งานจริง
