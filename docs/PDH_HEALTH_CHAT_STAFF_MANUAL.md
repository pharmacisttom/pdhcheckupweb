# Staff manual
1. Activate staff account and enroll MFA using existing onboarding. Administrator gives chat permissions and explicit department membership in /admin/chat/settings. Job title/department profile alone grants no chat access.
2. Open /admin/chat, select waiting conversation and รับบทสนทนา. Reply only after accepting. Internal note checkbox keeps note private; verify before sending. Assigned menu changes responsible staff where allowed. Transfer selects destination department; you may lose access immediately.
3. Resolve when answered, close when complete, reopen only appropriate resolved/closed matter. Avoid copying identifiers/health details into KB. Existing booking workflow remains separate; chat never claims appointment confirmation.
4. Knowledge drafts require independent review and publisher action. Clinical content requires qualified authorized reviewer.
5. Reports contain aggregates/approved question titles, no raw user questions. CSV/XLSX generated from authorized report data.

Service is initially disabled until real approved notice/retention and membership configured. Browser and real device acceptance are separate.
