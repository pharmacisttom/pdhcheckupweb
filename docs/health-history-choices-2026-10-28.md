# รายการเลือกและเพิ่มประวัติสุขภาพ — 28 ตุลาคม 2569

ปรับสามช่อง: medicalHistory, currentMedication และ allergies

- เลือก ไม่มี / ไม่ทราบ / มี — เลือกรายการหรือเพิ่มเอง
- กรณีมี เลือก checkbox ได้หลายรายการ และเพิ่ม/แก้ไข/ลบรายละเอียดเองได้สูงสุด 20 รายการต่อช่อง
- รองรับข้อความหลายบรรทัดของแบบร่างเดิม ไม่แยกหรือคาดเดาโรคจากข้อความเดิม; ค่าที่ตรง ไม่มี/ไม่ทราบ จะแสดงตัวเลือกที่สอดคล้องกัน
- เมื่อเลือก ไม่มี/ไม่ทราบ จะล้าง codes/custom เพื่อไม่เก็บข้อมูลขัดกัน
- ใช้ healthSelections แบบ optional ใน encrypted person payload โดยเก็บรหัสคงที่แยกจากข้อความแปล และสร้างข้อความสรุปในสามฟิลด์เดิมเพื่อให้หลังบ้านและแบบร่างเก่ายังใช้งานได้
- Client/server ตรวจรหัสที่อนุญาต รายการว่าง รายการซ้ำ ความยาวรวม และความสอดคล้องระหว่างข้อมูลโครงสร้างกับข้อความสรุป
- รายการเหล่านี้เป็นข้อมูลที่ผู้ใช้แจ้ง ไม่ใช่การวินิจฉัย แนะนำยา หรือเกณฑ์ประเมินความเสี่ยง ไม่เปลี่ยนกฎแบบประเมินที่อนุมัติไว้
- เพิ่มคำแปล UI/ตัวเลือกทั้งห้าภาษา; คำแปลสุขภาพยังอยู่ในขอบเขตที่ต้องให้ผู้เชี่ยวชาญตรวจทาน
- ไม่เพิ่ม health data ใน URL/log/localStorage และไม่เรียกบริการแปล/รายการยาภายนอก
- OTP ยังปิดตามคำสั่งล่าสุด ไม่มี migration หรือ production deployment ในงานนี้

ไฟล์หลัก: src/lib/health-history.ts, src/components/health-history-picker.tsx, src/components/registration-wizard.tsx, src/lib/domain.ts, src/app/globals.css และ dictionaries ห้าภาษา
