# Design system

Thai-first interface with deep teal sidebar #073F4A, primary #008577 (adjusted for white text contrast), dark #075E60, background #F4F8FA, text #163047, muted #64748B, border #E2E8F0. Local Thai system font fallbacks Sarabun / Noto Sans Thai / Tahoma are used without remote font requests. Supply an approved self-hosted Thai font asset before final visual QA.

Reusable Brand, PageHeader, PackageCard, Radix Modal, EmptyState, ErrorState, Loading, StatusBadge and shared forms. Homepage illustration is CSS and Lucide, not a fabricated hospital photograph/logo. Brand text denotes the project; the generic pulse glyph is a UI symbol, not the hospital's official seal. No hospital contact details are invented.

Desktop split hero, package grid, six-step progress, sticky quote summary; mobile single-column forms and collapsible admin navigation. Keyboard focus outlines, labels, skip link, Thai language metadata, status text alongside color, reduced-motion and print styles. WCAG AA is a target requiring formal verification, not a completed certification.

Reference screenshots were not included with the actual attachment. Styling follows written tokens and composition requirements. Screenshot fidelity cannot be asserted.
