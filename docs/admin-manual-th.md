# คู่มือเจ้าหน้าที่

เข้าสู่ระบบด้วยบัญชีที่ผู้ดูแลกำหนด ไม่ใช้บัญชีหรือรหัสผ่านตัวอย่างในงานจริง สิทธิ์แต่ละบทบาทควบคุมที่ API แม้ลิงก์เมนูปรากฏก็อาจไม่มีสิทธิ์ดำเนินการ

**เปลี่ยนรหัสผ่าน:** เลือกเมนู “เปลี่ยนรหัสผ่าน” หรือเปิด `/admin/change-password` กรอกรหัสผ่านเดิม รหัสผ่านใหม่อย่างน้อย 14 ตัวอักษร (ไม่เกิน 72 ไบต์) และยืนยันให้ตรงกัน รหัสใหม่ต้องแตกต่างจากเดิม เมื่อสำเร็จ ระบบออกจากทุกอุปกรณ์และให้เข้าสู่ระบบใหม่ การเปลี่ยนนี้ทำได้เฉพาะบัญชีของตนเอง มีการจำกัดจำนวนครั้งและบันทึกเหตุการณ์โดยไม่บันทึกรหัสผ่าน

**ภาพรวม:** เลือกช่วงวันที่นัดหมาย ดูจำนวน สถานะ และมูลค่าประมาณการ มูลค่านี้ไม่ใช่รายได้รับชำระ ไม่มีข้อมูลเมื่อไม่มีรายการจริง

**แพ็กเกจ:** เพิ่มแพ็กเกจฉบับร่าง เลือกรหัสบริการและราคาเหมาจ่าย ใช้รหัสตระกูลเดิมเพื่อสร้างเวอร์ชันใหม่ ต้องให้ผู้มีสิทธิ์อนุมัติก่อนเผยแพร่ เก็บถาวรแทนลบประวัติ

**นำเข้าราคา:** ดาวน์โหลดแม่แบบ ใส่รหัสและราคาที่ตรวจสอบแล้ว อัปโหลด CSV/XLSX ตรวจข้อผิดพลาด รายการใหม่ ราคาเดิม/ใหม่ และชื่อที่ไม่ตรง ต้องให้ผู้อนุมัติคนละคนดำเนินการ ราคาเผยแพร่เป็นเวอร์ชันใหม่ ไม่แก้ราคาในใบนัดเดิม

**นัดหมาย:** เพิ่มช่วงเวลาและความจุรายวัน รับ QR token จากเครื่องสแกนเพื่อเช็กอิน เปลี่ยนสถานะตามลำดับ ยกเลิกต้องมีเหตุผล การเปลี่ยนจากเสร็จสิ้นกลับเป็นนัดใหม่ไม่อนุญาต

**เปิด–ปิดรับนัดออนไลน์:** ไปที่ `/admin/booking-control` ผู้จัดการหรือ superadmin เลือกเปิดรับนัด หรือยกเลิกเครื่องหมายเพื่อปิดชั่วคราว แก้ข้อความแจ้งผู้รับบริการ แล้วกด “บันทึกรูปแบบรับนัด” เปิดกลับได้จากหน้าเดิม มีผลทันทีโดยไม่ต้องรีสตาร์ตระบบ เมื่อปิดจะไม่เปิดให้เลือกเวลา สำรองคิว ยืนยัน หรือเลื่อนนัดออนไลน์ รวมถึงคำขอจากหน้าที่เปิดค้างไว้ นัดเดิม การยกเลิกนัด และงานเจ้าหน้าที่ยังคงอยู่ การปิดรายวันยังตั้งค่าแยกในปฏิทินให้บริการได้

**คำขอให้ติดต่อนัด:** เมื่อปิดรับนัด ผู้ใช้ยืนยัน OTP กรอกข้อมูลและแบบประเมิน เลือกรายการ แล้วส่งข้อมูลให้เจ้าหน้าที่แทนการเลือกวันเวลา เปิด `/admin/contact-requests` ด้วยสิทธิ์งานลงทะเบียนหรือผู้จัดการ ดูข้อมูลติดต่อ รายการประมาณการและแบบประเมิน แล้วบันทึกสถานะ “รอติดต่อ / ติดต่อแล้ว / นัดรับบริการแล้ว / ปิดรายการ” พร้อมหมายเหตุหรือวันเวลาที่ตกลง ข้อมูลส่วนบุคคลและหมายเหตุเก็บแบบเข้ารหัส มีบันทึกการเข้าดูและแก้ไข แสดงรายการล่าสุดสูงสุด 200 รายการและกรองสถานะได้ การระบุว่านัดแล้วเป็นบันทึกการนัดโดยเจ้าหน้าที่ ไม่สร้างใบนัด QR ไม่กันโควตาออนไลน์ และไม่เรียกเก็บเงินอัตโนมัติ

**องค์กรและการเงิน:** ข้อมูลองค์กรในฉบับนี้เป็นฉบับร่าง รายชื่อพนักงานและสัญญายังไม่เปิดใช้งาน ใบประมาณการแยกจากยอดเรียกเก็บและรับชำระ ไม่มีการจำลองยอดเงินสำเร็จ

**รายงานและข้อมูลส่วนบุคคล:** ส่งออกได้เฉพาะรายงานสรุปตามสิทธิ์ ระบบบันทึกการส่งออก DPO ตรวจคำขอใช้สิทธิหลังยืนยันตัวตนและตามนโยบายโรงพยาบาล การลบข้อมูลทางคลินิก/การเงินต้องผ่านขั้นตอนอนุมัติ ไม่ลบโดยอัตโนมัติ
